Huddle

Видеоуроки: демонстрация экрана, рисование поверх слайдов, удалённое управление.

Скачать

Другая система: для Mac · для Windows

Установка на Mac

  1. Откройте скачанный файл Huddle-mac-universal.dmg и перетащите Huddle в папку «Программы».
  2. Откройте Терминал (⌘ + пробел, наберите «Терминал»), вставьте команду и нажмите Enter — она снимает запрет на запуск приложения из интернета: xattr -cr /Applications/Huddle.app
  3. Запустите Huddle из «Программ». При первой демонстрации экрана macOS попросит разрешения «Запись экрана», а при удалённом управлении — «Универсальный доступ»: включите Huddle в настройках и перезапустите приложение.

Нужна macOS 12 Monterey или новее.

Запуск на Windows

  1. Запустите скачанный файл Huddle-win-Setup.exe — установка займёт несколько секунд, без прав администратора; Huddle появится на рабочем столе. Дальше он обновляется сам.
  2. Если Windows покажет синее окно «Система Windows защитила ваш компьютер» — нажмите «Подробнее», затем «Выполнить в любом случае».
  3. Если антивирус (Dr.Web, Касперский) спросит про доступ в интернет — разрешите.

Дальше

В приложении нажмите «Создать новый урок» или вставьте ссылку на урок, которую вам прислали.
